White Hat

Source: ProPublica / NYC CCRB.

A few choices keep the data in this graph from misleading anyone reading it:

  • No y-axis manipulation: the axis starts at zero, therefore the bars show the actual gaps between groups instead of being inflated.
  • No filter manipulation: every group with at least 30 decided allegations is included.
  • No title manipulation: the title only describes what the chart shows instead of making inferred claims.
  • Sample sizes shown: each label includes n, so it can be clear if a rate is based on only a few allegations.

Black Hat

Source: ProPublica / NYC CCRB.

This is the same exact data, but manipulated in a few ways to intentionally mislead somebody reading it:

  • Y-axis manipulation: the beginning of the y-axis is inflated, so small differences between different groups appear to be much larger gaps.
  • Filter manipulation: The Unknown group was dropped from the dataset and only the 5 largest groups were chosen.
  • Title manipulation: the title makes bold claims about the system failing certain groups vs. others, which is an impossible conclusion to draw from this data alone.
